현재 연결된 파일이 없습니다.

새 파일 이름은 계좌정보.json입니다. 생성 후 Drive에서 원하는 폴더로 옮겨도 계속 연결됩니다. 목록에는 이 앱이 만들거나 접근 권한을 받은 파일만 나옵니다.

Google 연결 전에도 입력 및 JSON 백업을 테스트할 수 있습니다.

JSON 백업과 복원

현재 목록을 PC에 백업하거나, 기존 JSON을 불러온 뒤 새 Drive 파일로 저장할 수 있습니다.

불러오기는 현재 목록을 교체합니다. JSON 항목은 bank, accountNumber, name, notes 문자열을 사용합니다.

연결이 안 될 때

Google Cloud에서 Drive API가 활성화되어 있는지, 테스트 사용자에 로그인할 이메일이 등록되어 있는지 확인하세요.

OAuth 클라이언트의 승인된 JavaScript 원본은 https://hhdongle.github.io 입니다. 인증이 만료되면 다시 연결하세요.

계좌정보는 Google 로그인으로 승인한 Drive 파일에 저장됩니다. 이 사이트의 공개 저장소에는 업로드되지 않습니다.
