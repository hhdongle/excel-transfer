주일경상비 이체파일 생성

계좌 원본에서 필요한 항목을 찾아 작업 목록에 추가하세요.

1. 계좌 원본 불러오기

0건

계좌정보 입력 페이지에서 만든 Drive JSON 또는 PC에 저장한 계좌정보 JSON을 불러오세요.

연결 안 됨

아직 계좌 원본을 불러오지 않았습니다.

원본은 검색에만 사용합니다. 작업 목록을 바꾸거나 내보내도 Drive의 계좌정보는 변경되지 않습니다.

2. 작업 목록 0건

변경 사항 없음

모든 행에 1원 이상의 원 단위 금액을 입력해야 엑셀을 생성할 수 있습니다. Enter를 누르면 다음 행 금액으로 이동합니다. JSON은 기타와 금액을 함께 보관하고, 엑셀은 은행·계좌번호·이름·금액 순서로 제목 행 없이 생성합니다.

합계 0원

주일경상비 작업 목록
순번은행계좌번호이름기타금액 (원)관리

추가된 항목이 없습니다.

작업 목록은 이 페이지를 닫으면 사라집니다. JSON Export로 보관하면 나중에 이어서 작업할 수 있습니다.

3. 계좌 검색

1건이면 바로 추가하고, 2건 이상이면 선택 창을 표시합니다. 같은 계좌도 여러 번 추가할 수 있습니다.

계좌 원본 JSON을 불러온 뒤 검색하세요.

검색 결과 선택

은행계좌번호이름기타선택

선택하면 작업 목록에 추가됩니다. 취소하려면 닫기 또는 Esc를 누르세요.

작업 목록 확인
계좌번호는 문자열로, 금액은 숫자로 저장합니다. 엑셀은 은행·계좌번호·이름·금액 네 열에 테두리와 천 단위 쉼표를 적용하며 노란색 강조는 넣지 않습니다.
