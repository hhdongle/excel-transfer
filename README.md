# excel-transfer

## 주일경상비 작업 목록

메인 메뉴의 주일경상비-이체파일-생성은 `transfer.html`로 연결됩니다. 계좌정보 입력 페이지와 관련 파일은 이 기능을 추가하면서 변경하지 않았습니다.

1. Drive 연결 후 계좌 원본 JSON을 선택하거나 PC의 계좌 JSON을 불러옵니다. Drive 원본은 읽기만 합니다.
2. 은행·계좌번호·이름·기타 중 일부를 입력하고 Enter를 누릅니다. 각 필드 안의 문자열 포함 여부로 검색하며 영문 대소문자는 구분하지 않습니다.
3. 결과 0건은 안내 메시지, 1건은 즉시 추가, 2건 이상은 선택 팝업으로 처리합니다. 원본의 중복 항목을 유지하며 같은 항목을 여러 번 추가할 수 있습니다.
4. 하단 작업 목록은 행 삭제, 전체 비우기, JSON Export/Import와 `.xlsx` 다운로드를 지원합니다. Import는 작업 목록을 교체하며 검색용 계좌 원본은 유지합니다.

JSON과 엑셀에는 `bank`, `accountNumber`, `name`, `notes`에 해당하는 네 항목만 들어가고 화면 순번은 제외됩니다. 엑셀 헤더는 은행·계좌번호·이름·기타입니다. 계좌번호와 수식처럼 보이는 문자열도 텍스트로 저장합니다. 은행별 실제 이체 업로드 서식, 금액·은행 코드 등은 아직 요청받지 않아 포함하지 않았습니다.

엑셀 생성은 공식 SheetJS CE 0.20.3의 브라우저용 mini 빌드를 프로젝트에 포함해 사용합니다. 출처: https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.mini.min.js. 라이선스는 `vendor/SheetJS-LICENSE.txt`에 있습니다. 엑셀·JSON 내보내기는 브라우저 내부에서 처리합니다. 실제 계좌 자료는 저장소에 포함하지 않습니다.

검사: `node --test tests/account-data.test.mjs tests/transfer.test.mjs`

GitHub Pages에서 사용하는 교회 재정 업무 메뉴와 계좌정보 입력 페이지입니다.

## Google Drive JSON 테스트

1. Google Cloud에서 Google Drive API를 활성화합니다.
2. 웹 애플리케이션 OAuth 클라이언트의 승인된 JavaScript 원본에 `https://hhdongle.github.io`를 등록합니다.
3. OAuth 앱이 테스트 상태라면 대상 > 테스트 사용자에 사용할 Google 이메일을 추가합니다.
4. 사이트에서 계좌정보-입력을 열고 Google Drive 연결을 누릅니다.
5. 테스트 계좌를 목록에 추가한 뒤 새 JSON 만들기를 누릅니다. 내 드라이브에 비공개 `계좌정보.json`이 생성됩니다.
6. 이후 추가·수정·삭제는 Drive에 저장 버튼을 눌러 반영합니다.
7. 다시 접속하면 연결 후 파일 목록에서 같은 파일을 선택하고 불러오기를 누릅니다.

파일은 생성 후 Drive에서 원하는 폴더로 옮겨도 파일 ID가 유지됩니다. `drive.file` 권한을 사용하므로 이 앱이 생성하거나 별도로 권한을 받은 파일만 목록에 보입니다. 임의의 기존 Drive 파일을 선택하는 Google Picker는 아직 제공하지 않습니다. 기존 로컬 JSON은 JSON 불러오기로 가져와 새 Drive 파일로 만들 수 있습니다.

OAuth 클라이언트 ID는 공개 식별자입니다. 클라이언트 보안 비밀번호와 액세스 토큰은 저장소에 넣지 않습니다. 액세스 토큰과 입력 목록은 페이지 메모리에서만 유지됩니다. 페이지를 닫기 전에 Drive에 저장하거나 JSON을 다운로드하세요. 연결 해제는 이 페이지 메모리의 토큰을 지우며 Google 계정에서 앱 권한 자체를 취소하지는 않습니다.

## JSON 형식

```json
[
  {
    "bank": "테스트은행",
    "accountNumber": "001-234-567",
    "name": "테스트 예금주",
    "notes": "테스트용 가상 계좌"
  }
]
```

빈 목록은 `[]`입니다. 계좌번호는 앞자리 0이 유지되도록 문자열로 관리합니다. 알 수 없는 필드와 숫자형 계좌번호는 실수로 데이터를 손실하지 않도록 불러오기를 거절합니다.

저장 전 Drive 버전을 비교해 외부 변경을 발견하면 덮어쓰기를 중단합니다. 이 파일 기반 방식은 여러 사용자의 동시 편집을 위한 트랜잭션 DB가 아니므로 동시에 편집하지 마세요. 충돌 시 현재 목록을 JSON으로 백업한 뒤 최신 Drive 파일을 불러옵니다.
